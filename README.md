# ✧ Mystic SQL Cards

**The Arcana of Database — Learn SQL Through Interactive Tarot Flashcards**

Mystic SQL Cards is a lightweight, interactive SQL learning game designed to help students practice fundamental SQL commands through a unique tarot-inspired flashcard experience.

Choose a mysterious card, reveal your challenge, solve the SQL problem, and uncover the answer!

## ✨ Features

- **40 Interactive Cards** — Explore 40 different SQL practice challenges.
- **Tarot-Inspired Design** — Dark purple and gold mystical card interface.
- **Random Card Selection** — Students freely choose cards from a shuffled deck.
- **No Repetition** — Selected cards cannot be chosen again during the same session.
- **Two SQL Commands** — Practice `SELECT` and `UPDATE`.
- **Three Difficulty Levels** — Easy, Medium, and Hard.
- **Answer Reveal** — Reveal SQL solutions with explanations.
- **Progress Tracking** — Monitor selected and remaining cards.
- **Responsive Design** — Works on desktop, tablet, and mobile devices.
- **Lightweight** — Built with vanilla HTML, CSS, and JavaScript.

## 🃏 Learning Content

The application contains 40 SQL challenges.

| SQL Command | Easy | Medium | Hard | Total |
|---|---:|---:|---:|---:|
| SELECT | 7 | 7 | 6 | 20 |
| UPDATE | 7 | 7 | 6 | 20 |
| **Total** | **14** | **14** | **12** | **40** |

### SQL Topics

- SELECT and UPDATE statements
- WHERE clause
- Comparison operators
- Logical operators (AND, OR)
- LIKE and IN
- BETWEEN
- Arithmetic operators (+, -, *, /)
- Column aliases (AS)

All exercises follow the W3Schools sample database schema.

## 🎮 How to Play

1. Open Mystic SQL Cards.
2. Choose one card from the tarot deck.
3. Read the SQL challenge.
4. Write your SQL query using MySQL.
5. Click **Reveal Answer** to check your solution.
6. Return to the deck and choose another card.
7. Complete all 40 challenges!

## 🚀 Run Locally

Clone this repository:

```bash
git clone https://github.com/USERNAME/mystic-sql-cards.git
```

Open the project folder:

```bash
cd mystic-sql-cards
```

Open `index.html` in your web browser.

No installation or build process is required.

## 🌐 GitHub Pages Deployment

This project can be hosted for free using GitHub Pages.

1. Create a GitHub repository.
2. Upload the project files.
3. Make sure the main HTML file is named `index.html`.
4. Navigate to **Settings → Pages**.
5. Select **Deploy from a branch**.
6. Choose the `main` branch and `/ (root)` folder.
7. Click **Save**.

Your application will be available at:

```text
https://USERNAME.github.io/mystic-sql-cards/
```

Mystic SQL Cards is designed as a supplementary learning tool for Informatics students, particularly for introductory database and SQL practical lessons.

It encourages students to practice SQL commands, understand query conditions, and develop problem-solving skills through a simple gamified learning experience.
